# Quickstart: 联邦学习任务重构

本指南帮助开发者快速理解和使用新的联邦学习任务系统。

## 概述

联邦学习任务系统支持 4 类二级菜单和 20+ 种具体任务， 每种任务都有详细的参数配置选项。

## 快速开始

### 1. 拖拽任务

1. 点击左侧边栏的"联邦学习"卡片
2. 选择"训练"或"推断" Tab 页
3. 选择二级菜单（预处理、特征工程、横向模型、纵向模型）
4. 将任务拖拽到画布上

### 2. 选择子类型

对于支持子类型的任务（如数据清洗）：
1. 在弹出的配置对话框中
2. 从下拉列表中选择子类型（如"缺失值处理"）
3. 子类型选择后不可更改

### 3. 配置参数

1. 填写任务名称
2. 根据需要填写各个参数
3. 参数验证错误会实时显示

### 4. 连接数据源

1. 从数据源节点拖拽连接线到任务节点
2. 系统会自动验证连接约束

### 5. 添加输出（仅多方隐私任务）

1. 点击任务节点下方的"+"按钮
2. 选择输出企业和字段

## 任务类型说明

### 单方本地任务
- **图标**: 无"添加输出"按钮
- **数据源**: 只能连接 1 个
- **输出**: 自动传递到下游任务
- **示例**: 数据清洗、特征编码、特征变换、特征缩放

### 动态任务
- **图标**: 根据
连接数量动态显示"添加输出"按钮
- **数据源**: 可连接 1 个或多个
- **行为**: 单数据源时为本地任务
，多数据源时为多方隐私任务
- **示例**: 数据采样、特征分箱、特征选择、特征相关性分析

### 多方隐私任务
- **图标**: 有"添加输出"按钮
- **数据源**: 必须连接 2+ 个
- **输出**: 需手动配置输出企业和字段
- **示例**: 所有横向和纵向模型

## 参数类型

| 类型 | 说明 | 示例 |
|------|------|------|
| number | 数字输入 | 学习率、迭代次数 |
| text | 文本输入 | 数据集名称 |
| select | 单选下拉 | 处理策略 |
| boolean | 开关 | 是否启用早停 |
| multiselect | 多选 | 选择要处理的列 |

## 常见问题

### Q: 为什么不能切换子类型？
A: 子类型选择后锁定是为了简化状态管理。如需更换子类型
，请删除节点后重新拖拽。

### Q: 为什么"添加输出"按钮消失了？
A: 动态任务在连接数量变化时会自动切换类型。单数据源时为本地任务
，不需要配置输出。

### Q: 为什么无法连接第二个数据源？
A: 单方本地任务只能连接 1 个数据源。请检查任务的执行类型。

## 示例流程

### 完整的联邦学习训练流程

```
数据源A ──┐
        ├── 数据清洗（缺失值处理）──┐
数据源B ──┘                         ├── 特征分箱（等频分箱）── 横向逻辑回归 ── 输出
                                  │
数据源C ────────────────────────────┘
```

### 步骤说明

1. 三个数据源分别进行数据清洗
2. 特征分箱任务连接清洗后的数据（多方隐私模式）
3. 横向逻辑回归连接特征分箱输出
4. 配置输出企业
