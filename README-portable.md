# 隐私计算流程编辑器 - 使用说明

## 运行方式

1. 解压 `隐私计算流程编辑器-win-x64.zip` 到任意目录
2. 双击运行 `隐私计算流程编辑器.exe`

## 系统要求

- Windows 10/11 (64位)
- 无需安装任何运行时环境

## 功能说明

这是一个基于 Vue Flow 的可视化流程图编辑器，支持：

- 拖拽创建数据源节点（MySQL、PostgreSQL、CSV、Excel、REST API、GraphQL）
- 拖拽创建计算任务节点（PSI、PIR、MPC、联邦学习、同态加密、差分隐私）
- 可视化连接节点
- 流动光点动画效果
- 节点属性配置

## 开发信息

- 技术栈: Vue 3 + TypeScript + Vite + Electron
- 构建时间: 2026-02-26
